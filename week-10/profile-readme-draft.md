# Rene Bubõr

**Finants- ja ärianalüüs | Juhtimisaruandlus · Kuluanalüüs · Andmekvaliteet**

Excel · Power BI ja DAX · PostgreSQL / Supabase · Python ja pandas · Plotly · Git
